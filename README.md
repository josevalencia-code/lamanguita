# La Manguita

Sitio web de la cabaña La Manguita, Mazamitla, Jalisco.

## Probar en local

    python3 -m http.server 8000

Abre http://localhost:8000

## Archivos

- index.html: contenido de la página
- styles.css: estilos (colores y tipografías en :root)
- script.js: formulario de WhatsApp (cambia WA_NUMBER)

## Pendiente
